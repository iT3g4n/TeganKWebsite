A VPN that works on networks that block VPNs

A desktop client for Windows, macOS and Linux that tunnels WireGuard through censorship-resistant transports, so to a firewall the connection looks like ordinary HTTPS. I built all of it: the app, the servers it connects to, and the site where people sign up and pay.

  • Electron app with a Go networking core
  • Dockerized server fleet running WireGuard and obfuscated proxies
  • React and Express site with PostgreSQL accounts and payments
  • Release builds for three operating systems, in eight languages
  • 1,200+ commits across the client, servers and site
